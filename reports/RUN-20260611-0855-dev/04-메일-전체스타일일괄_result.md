## TC-01: 전체 글자 크기 일괄 변경 — ❌ FAIL (크기 역방향)
- 입력: "본문 전체 글자 크기를 한 단계 키워줘"
- **결함**: AI 가 현재 크기를 읽지 않고 **기본을 10pt로 가정** → "11pt로 한 단계 키웠다"고 응답했으나, 실제 기본은 16px(12pt)이라 **11pt(14.67px)로 오히려 작아짐**(키우라는 요청에 축소). 전 문단 균일 적용·내용·표 보존은 정상.
- 기대: 전 문단 크기 **증가** / 실제: 전 문단 14.67px 로 **감소**.
- 추정 원인: 현재 폰트 크기 미조회 + 기본값 10pt 가정. "키워줘" 류 상대 명령에서 현재값을 안 읽으면 역방향 발생.
- 토큰 in 5.2k / out 2.0k. wait_ms 38s.
