## TC-03: 제목/소제목 스타일 적용 — ❌ FAIL (본문 내용 손실)
- 입력: "메일 제일 윗줄을 제목 스타일로, 각 섹션 첫 줄을 소제목 스타일로 만들어줘"
- 스타일 적용 자체는 동작: 인사말 → H1(24px 굵게), 각 섹션 첫 문장 → H2(18px 굵게), 맺음말·표는 일반 유지.
- **결함**: AI 가 `replace_editor_block` 로 각 단락을 **첫 문장만 남기고 나머지 문장을 삭제**. 손실된 내용:
  - "이번 워크숍은 6월 27일 금요일 오후 2시부터 강남 본사 5층 대회의실에서 진행됩니다." (**일시·장소**)
  - "모든 팀원의 적극적인 참여를 부탁드립니다."
  - "문의사항은 총무팀 김민수 대리에게 연락 주세요." (**연락처**)
- AI 응답은 "각 소제목 아래 나머지 문장은 본문 스타일로 그대로 유지"라고 설명했으나 **실제로는 삭제됨**(응답과 결과 불일치).
- 기대: 제목/소제목 스타일 적용 + **본문 텍스트 불변** / 실제: 스타일 적용됐으나 단락별 둘째 문장 이후 전부 소실.
- 추정 원인: heading 변환을 "단락 = 한 줄 제목"으로 오해해 둘째 문장을 버리는 `replace_editor_block` 사용. 단락 내 첫 줄만 heading 화하고 잔여를 별도 본문 블록으로 분리해야 하는데 누락.
- **추가 관찰(성능)**: 응답이 **~100초**로 60초 한도 크게 초과. (토큰 in 11.9k / out 8.9k — 4회 `replace_editor_block` 순차 호출, Sonnet 과다추론 + 출력 과다.)
