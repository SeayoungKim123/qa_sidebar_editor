## 핵심 결론 — PPT 열린 덱 실시간 편집 불가 (신규 이슈)
PPT 시나리오의 검증 전제는 "AI가 **열려 있는 OnlyOffice 프레젠테이션**의 슬라이드를 편집/추가"하는 것이다. 그러나 실측 결과:
- 매 생성 요청마다 **Native / HTML 이미지 방식 선택 UI**가 먼저 뜬다. **Native(편집 가능)** 를 선택해도,
- AI는 **OnlyOffice 전용 native 슬라이드 도구가 없다**고 명시하고, 샌드박스(pptxgenjs / add_slide.py)로 **별도 PPTX 파일을 생성**하거나 "수정할 원본 파일 경로를 확보하지 못했다"며 우회를 시도한다.
- 결과적으로 **열린 에디터의 슬라이드 패널은 1장(placeholder) 그대로** — 제목/부제/본문/추가 슬라이드가 전혀 반영되지 않는다.
- 1회 생성에 **약 2~3분** 소요(샌드박스 파일 빌드 + 검증 시도).

이 한 가지 갭이 시나리오 전체(단계적 덱 진화 전제)를 무력화한다.
