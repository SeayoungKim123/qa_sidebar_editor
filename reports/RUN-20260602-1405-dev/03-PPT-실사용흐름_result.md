## 핵심 변화 — 코드 인터프리터 OFF로 ISS-006 해소
직전 v4 회차에서 PPT는 0/9였다. 원인은 AI가 열린 덱을 네이티브 편집하지 않고 코드 인터프리터(샌드박스)로 별도 다운로드용 PPTX만 만든 것(ISS-006).
이번 회차는 채팅 입력창 `+` → **[코드 인터프리터] OFF** 로 설정 후 진행. 그러자 AI가 첫 프롬프트에서 **Native(편집 가능) / HTML 이미지** 방식을 물었고, **Native** 선택 시 `get_deck_overview` · `get_native_deck_state` · `set_native_deck_style` · `compose_native_slide` · `patch_native_slide` · `update_slide_element_style` 등 **네이티브 슬라이드 도구로 열린 덱을 직접 편집**했다. 9개 TC 전부 성공.

## 사용자 흐름
빈 PPTX 1장에서 시작 → 표지·본문·데이터 슬라이드 생성(1단계) → 개별 요소 수정(2단계) → 전체 테마·제목·표지 일괄 재서식(3단계). 덱이 단계적으로 진화.
