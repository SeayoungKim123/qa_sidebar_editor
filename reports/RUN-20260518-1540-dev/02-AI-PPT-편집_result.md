## TC-02: 글자 크기 조정 — ❌ FAIL

- **입력**: "선택한 제목 글자 크기를 36pt로 키우고 굵게 해줘"
- **조작**: 슬라이드 1 제목 텍스트박스 클릭(shape 선택) → AI 채팅창에 프롬프트 입력 → 전송
- **AI 응답 1**: "선택된 텍스트가 감지되지 않아서 바로 적용하진 못했어요."
- **추가 시도**: 더블클릭 + Ctrl+A로 텍스트 편집 모드 진입 후 재전송
- **AI 응답 2**: "아직 선택된 텍스트가 감지되지 않아요. 제목 텍스트 자체를 편집 상태로 클릭한 뒤 글자를 드래그 선택해 주세요."
- **기대**: 제목 폰트 36pt + Bold 적용
- **실제**: 미적용 (제목 서식 변경 없음)
- **원인**: AI 채팅창 입력 시 ONLYOFFICE 편집기 포커스 이탈 → `get_selected_text` 반환값 없음. 텍스트 선택 유지와 AI 채팅 입력이 물리적으로 양립 불가.

## TC-06: 전체 슬라이드 제목 폰트 통일 — ❌ FAIL

- **입력**: "모든 슬라이드 제목을 'Pretendard' 폰트, 32pt, 굵게로 통일해줘"
- **조작**: 선택 없이 AI 채팅창에 프롬프트 입력 → 전송
- **AI 처리 흐름**:
  1. `get_native_deck_state` → 슬라이드 수/캔버스 정보만 반환, 제목 도형 구조 없음
  2. 드라이브 검색 → 파일 Markdown 내용 추출(제목 후보 파악)
  3. 편집 URL 웹크롤링 시도 → 접근 불가
  4. 대안 탐색 지속 → 실질적 편집 미수행
- **기대**: 모든 슬라이드(10장) 제목에 Pretendard/32pt/Bold 일괄 적용
- **실제**: 슬라이드 제목 변경 없음
- **원인**: `get_native_deck_state`가 도형 세부 구조(제목 텍스트박스 위치·내용)를 반환하지 않아 AI가 각 슬라이드 제목을 타겟팅 불가. 기존 native 슬라이드 요소 일괄 수정 API 미지원.
