## TC-01: 표 만들기 — ✅ PASS

- 입력: `"여기에 3행 4열 표 만들어줘. 헤더는 이름/부서/직급/입사일"`
- AI 도구: `insert_table(rows=3, cols=4, headerRow=true, data=...)` Approved
- 결과: 본문 끝에 3행 4열 표 + 정확한 헤더 4개. DOCX 네이티브 표 객체.
- 스크린샷: `screenshots/01-docx-tc01-07-doc-end.png`

## TC-02: 글자 크기 조정 — ❌ FAIL

- 입력: `"선택한 단락 글자 크기를 16pt로 키워줘"`
- AI 도구: `format_text_blocks(contentIndexes=[5], fontSize=16)` Approved
- 응답: "16pt로 키웠습니다"
- 실제: 단락 글꼴 콤보 표시 **`8`** (16 아님). 단락이 시각적으로 더 작아짐.
- 추정: `format_text_blocks` 의 fontSize 인자 처리에서 단위 변환 버그 (16 → 8, half-point 가능성)
- 스크린샷: `screenshots/01-docx-tc02-05-font-check.png`

## TC-03: 회사 소개 3문단 작성 — ✅ PASS

- AI 도구: `create_document` 스킬 조회 후 `insert_document_blocks(blocks=[paragraph x3])` Approved

- 스크린샷: `screenshots/01-docx-tc03-09-doc-end-final.png`

- 추정: AI가 도구 호출을 안 했거나 적용 실패.
- 스크린샷: `screenshots/01-docx-tc05-02-after-pgup.png`

## TC-07: 표지 페이지 디자인 — ✅ PASS

- **TC-05 글머리 기호**: AI 응답은 정상, 도구 호출 미수행 or 적용 누락
- **TC-09 일괄 스타일**: 응답 완료했으나 시각 변화 미미. 탐색창 검증 필요.
- **TC-08 BLOCKED**: 시나리오 사전조건(II 아래 표) 부합하지 않는 파일 사용 — 시나리오 개정 필요.

### 주요 권장 액션

1. **TC-02 우선 이슈**: `format_text_blocks` 의 fontSize 단위 처리 점검. 16pt 입력 → 8pt 적용은 명확한 회귀 후보.
2. **TC-05 도구 호출 추적**: 글머리 기호 변환 시 어떤 도구가 호출되는지 / 호출이 안 됐는지 로그 확인.
3. **TC-09 스타일 적용 검증**: 탐색창에서 "제목 2" 스타일 인식 여부 확인. 적용 실패면 도구 매핑 점검.
4. **시나리오 사전조건 보강**: TC-05 (평문 3줄 단락), TC-08 (II 아래 표) 사전조건이 실제 테스트 파일과 맞지 않음. 시나리오 갱신 또는 사전 셋업 절차 추가 필요.
