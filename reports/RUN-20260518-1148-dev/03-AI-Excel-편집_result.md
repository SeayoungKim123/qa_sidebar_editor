2. **시트 전환 불가** (TC-04): AI가 시트2를 활성화하지 못해 시트1에 수식 삽입
3. **셀 정렬 미지원** (TC-06): 가운데 정렬 명령이 적용되지 않음 (테두리는 정상)
4. **VLOOKUP 시트명 오류** (TC-09): AI가 한글 시트명 "시트2" 대신 영문 "Sheet2"로 수식 작성
5. **파이 차트 전제조건 미달** (TC-11): 테스트 데이터가 범위에 없어 검증 불가
6. **차트 서식 변경 도구 없음** (TC-12): 기존 차트의 색상/축/격자선 수정 API 미제공
