# 시나리오: AI Excel 스프레드시트 편집

## 메타 정보
- **ID**: SCN-03
- **우선순위**: P0
- **목적**: ONLYOFFICE 스프레드시트 편집기에서 우측 AI 사이드패널 채팅창에 자연어 명령을 입력했을 때, 셀/표/서식이 명령 의도대로 정확히 편집되는지 검증
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 우측 AI 어시스턴트 사이드패널 노출, 모델 `GPT 4.1` 선택
  - 테스트용 XLSX 1개 열림 (Sheet1 비어있음, Sheet2 에 샘플 데이터 A1:C10 입력 — 헤더 + 9행 더미)
  - 편집 모드 활성화

---

## 사용자 흐름

1. XLSX 열기 → 편집 모드
2. 작업 대상 시트/셀 범위 선택
3. 우측 AI 채팅창에 자연어 명령 입력 → 전송
4. 셀 값/수식/서식이 변경되는지 확인
5. 저장 → 재오픈하여 영속 확인

---

## 테스트 케이스

### TC-01: 표 만들기 — "A1:C5 가계부 표"
- **입력**:
  - Sheet1 빈 상태, A1 셀 선택
  - 프롬프트: `"A1부터 C5까지 가계부 표 만들어줘. 헤더는 날짜/항목/금액, 예시 데이터 4행 채워줘"`
- **조작 순서**:
  1. Sheet1 A1 클릭
  2. 프롬프트 전송
- **기대 결과**:
  - A1:C1 에 헤더 (날짜/항목/금액)
  - A2:C5 에 더미 데이터 4행 (날짜 형식, 항목 텍스트, 금액 숫자)
- **검증 포인트**:
  - 금액 컬럼의 데이터 타입이 숫자 (좌측 정렬이 아닌 우측 정렬)
  - 날짜 컬럼이 날짜 형식으로 인식
  - 표 외 영역(D, E 등)에 영향 없음

### TC-02: 글자 크기/서식 — "헤더 행 굵게 + 배경 회색"
- **입력**:
  - TC-01 의 표 또는 사전 데이터의 헤더 행(A1:C1) 선택
  - 프롬프트: `"선택한 헤더 행을 굵게 + 글자 크기 14pt + 배경색 연회색(#E5E5E5)으로 해줘"`
- **조작 순서**:
  1. A1:C1 드래그 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 헤더 행 셀이 굵게, 14pt, 배경 연회색
- **검증 포인트**:
  - 헤더 셀 각각 폰트 크기 `14`, Bold 활성
  - 데이터 행(2행 이하)은 영향 없음
  - 표 외부 셀 무변동

### TC-03: 내용 작성 — "B열에 1월~12월 채워줘"
- **입력**:
  - Sheet1 B1 셀 선택
  - 프롬프트: `"B1부터 아래로 1월부터 12월까지 입력해줘"`
- **조작 순서**:
  1. B1 선택
  2. 프롬프트 전송
- **기대 결과**:
  - B1:B12 에 `1월` ~ `12월` 텍스트 채워짐
  - 빠진 월 없음, 순서 정확
- **검증 포인트**:
  - 12개 셀 정확히 채워짐 (B13 은 비어있음)
  - 다른 열 영향 없음

### TC-04: 수식 — "B열 합계를 B11 에 넣어줘"
- **입력**:
  - Sheet2 의 B2:B10 에 숫자 데이터 존재
  - 프롬프트: `"B2부터 B10까지 합계를 B11 셀에 SUM 수식으로 넣어줘"`
- **조작 순서**:
  1. Sheet2 활성화
  2. 프롬프트 전송
- **기대 결과**:
  - B11 에 `=SUM(B2:B10)` 수식 삽입
  - 결과값이 B2:B10 합과 일치
- **검증 포인트**:
  - B11 클릭 시 수식 입력줄에 `=SUM(B2:B10)` 표시 (텍스트 값 아님)
  - 합계 값을 수동으로 검산해 일치
  - B12 이하는 비어있음

### TC-05: 셀 서식 — "금액 컬럼 통화 형식"
- **입력**:
  - 금액 컬럼(C열 또는 사전 데이터의 숫자 컬럼) 선택
  - 프롬프트: `"선택한 컬럼을 한국 원화(₩) 통화 형식으로 바꿔줘"`
- **조작 순서**:
  1. C2:C10 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 각 셀 값 앞에 `₩` 통화 기호 표시
  - 셀의 실제 데이터 값은 유지 (서식만 변경)
- **검증 포인트**:
  - 셀 클릭 시 수식 입력줄에는 숫자만 표시 (서식만 적용됨)
  - 셀 서식 메뉴에서 "통화" 카테고리 선택 상태
  - 헤더 행은 영향 없음

### TC-06: 정렬/형식 맞추기 — "표 정렬 + 테두리"
- **입력**:
  - 데이터 표 영역(예: A1:C10) 선택
  - 프롬프트: `"선택 영역을 가운데 정렬하고, 모든 셀에 얇은 검은색 테두리 적용해줘"`
- **조작 순서**:
  1. 표 범위 드래그
  2. 프롬프트 전송
- **기대 결과**:
  - 모든 셀 가운데 정렬
  - 셀 전체에 테두리 적용
- **검증 포인트**:
  - 셀 정렬 표시가 가운데
  - 시각적으로 테두리 격자 노출
  - 표 외부 영역은 정렬·테두리 변동 없음

### TC-07: 복합 명령 — "표 + 합계 + 서식"
- **입력**:
  - Sheet1 빈 상태, A1 선택
  - 프롬프트: `"A1:C6에 3명의 1~5월 매출 표 만들고, B7~C7 에 각 컬럼 합계 SUM 수식 넣고, 헤더 굵게 처리해줘"`
- **조작 순서**:
  1. A1 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 6행 3열 표 + 7행 합계 행 + 헤더 굵게
- **검증 포인트**:
  - 셋 다 만족해야 PASS, 하나라도 빠지면 `FAIL` (note 에 무엇이 빠졌는지 기록)
  - 합계 셀이 텍스트 값이 아닌 수식

### TC-08: 비대상 명령 — "이 시트를 PDF로 변환해서 다운로드"
- **입력**: 프롬프트 `"이 시트를 PDF로 변환해서 다운로드 받게 해줘"`
- **조작 순서**: 프롬프트 전송
- **기대 결과**:
  - 불가 안내 또는 대안 제시
  - 시트 셀 변경 없음
- **검증 포인트**:
  - 셀 변경 0건
  - 명시적 거절/안내 노출
