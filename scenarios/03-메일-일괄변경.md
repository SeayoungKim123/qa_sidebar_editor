# 시나리오: 메일 AI 사이드패널 — 블록·구조 서식 삽입 (표·가로선·제목·정렬)

## 메타 정보
- **ID**: SCN-03
- **우선순위**: P1
- **목적**: 선택과 무관하게 본문에 **블록/구조 서식 요소**(표·가로선·제목 스타일·정렬)를 삽입·적용하는 요청을 AI 가 올바른 구조로 정확히 수행하는지, 그리고 본문 **내용을 보존**하는지 검증. **텍스트 내용 가공이 아니라 서식·구조 적용이 검증 대상.** (본문 전체 스타일을 한 번에 바꾸는 전역 일괄 명령은 **SCN-04** 에서 별도 검증.)
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 메일 → 메일 쓰기 진입, 상단 **보라색 AI 아이콘**으로 AI 사이드패널 노출
  - **여러 문단·나열 항목이 채워진 메일** 준비 (SCN-01 산출물 재사용 권장)
- **검증 규칙**: 본문 직접 조작 **금지**. 프롬프트만 사용. **AI 는 본문만 편집**. 요소 삽입 시 **구조 깨짐·본문 내용 손실**이면 `FAIL`. 전체 일괄 명령이 일부 문단만 적용하고 누락하면 `FAIL` + 누락 항목 note 기록.

## 사용자 흐름

선택 없이 전송하는 명령으로 본문에 구조 요소를 넣거나 블록 스타일을 입힌다. 서식은 누적되며, 뒤 명령이 앞 결과 위에 덮인다. 선행 본문이 없으면 후속 TC 는 `BLOCKED`.

1. **표 삽입** — 행·열 지정 표
2. **가로선 삽입** — 구분선
3. **제목 스타일** — 제목/소제목 스타일 적용
4. **문단 정렬** — 가운데/우 정렬

## 테스트 케이스

### TC-01: 표 삽입 (행·열 지정)
- **입력**:
  - 프롬프트: `"본문에 3행 2열짜리 표를 넣어줘. 첫 행은 제목 행으로 해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 지정한 행·열 수의 표가 본문에 삽입 (첫 행 헤더)
- **검증 포인트**: 행·열 수 일치(3×2) · 표 구조 정상(깨짐 없음) · 기존 본문 텍스트 보존

### TC-02: 가로선(구분선) 삽입
- **입력**:
  - 프롬프트: `"인사말과 본론 사이에 가로 구분선을 하나 넣어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 지정 위치(인사말과 본론 사이)에 가로선(구분선) 삽입
- **검증 포인트**: 가로선이 지정 위치에 삽입됨 · 본문 내용 무변동 · 구분선 1개만(중복 삽입 없음)

### TC-03: 제목/소제목 스타일 적용
- **입력**:
  - 프롬프트: `"메일 제일 윗줄을 제목 스타일로, 각 섹션 첫 줄을 소제목 스타일로 만들어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 해당 줄들이 제목/소제목(heading) 스타일로 변경
- **검증 포인트**: 제목·소제목 스타일 적용 · **본문 텍스트 불변** · 일반 문단은 스타일 미적용

### TC-04: 문단 정렬
- **입력**:
  - 프롬프트: `"맺음말 단락을 오른쪽 정렬로 바꿔줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 지정 문단(맺음말)이 오른쪽 정렬로 변경
- **검증 포인트**: 지정 문단 정렬 적용 · 다른 문단 정렬 무변동 · 내용 불변
