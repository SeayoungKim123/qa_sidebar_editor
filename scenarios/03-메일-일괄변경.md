# 시나리오: 메일 AI 사이드패널 — 여러 요소 한번에 변경하기

## 메타 정보
- **ID**: SCN-03
- **우선순위**: P1
- **목적**: 선택 없이 **본문 전체에 작용하는 일괄 명령**(전체 톤 변환·글머리 정리·전체 다듬기·전체 번역)을 AI 가 전역으로 일관되게 적용하는지, 그리고 **앞서 부분 적용한 서식/표현이 일괄 명령에 덮이는지**를 검증
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 메일 → 메일 쓰기 진입, 상단 **보라색 AI 아이콘**으로 AI 사이드패널 노출
  - **여러 문단·나열 항목이 채워진 메일** 준비 (SCN-01 산출물 재사용 권장)
- **검증 규칙**: 본문 직접 조작 **금지**. 프롬프트만 사용. **AI 는 본문만 편집**. 일괄 명령이 일부 항목만 처리하고 누락하면 `FAIL` + 누락 항목 note 기록.

---

## 사용자 흐름

선택 없이 전송하는 전역 명령으로 메일 전체를 한 번에 재가공한다. 일괄 명령은 누적되며, 뒤 명령이 앞 결과 위에 덮인다.

1. **전체 톤 변환** — 메일 전체를 다른 톤으로
2. **글머리 기호 정리** — 본문 나열 부분을 불릿으로 일괄 정리
3. **전체 내용 다듬기** — 문장 매끄럽게 일괄 윤문
4. **전체 번역** — 메일 전체를 다른 언어로

## 테스트 케이스

### TC-01: 전체 톤 변환
- **입력**:
  - 프롬프트: `"메일 전체를 가벼운 캐주얼한 톤으로 바꿔줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 모든 문단의 어조가 캐주얼로 일괄 전환
- **검증 포인트**: 전 문단 톤 일관 적용 · 내용 누락 없음 · 한두 문단만 바뀌면 `FAIL`(누락 note)

### TC-02: 글머리 기호 정리
- **입력**:
  - 프롬프트: `"본문에서 나열되는 부분을 글머리 기호 목록으로 정리해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 나열 항목이 불릿 목록으로 변환
- **검증 포인트**: 나열 항목이 불릿으로 표시 · 일반 문단은 목록화되지 않음 · 항목 수 보존

### TC-03: 전체 내용 다듬기
- **입력**:
  - 프롬프트: `"메일 전체 내용을 매끄럽고 자연스럽게 다듬어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 전체가 윤문되되 의미·구조 유지
- **검증 포인트**: 전체 문장 다듬어짐 · 핵심 정보 누락 없음 · TC-02 글머리 구조 보존 여부 확인 후 note

### TC-04: 전체 번역
- **입력**:
  - 프롬프트: `"메일 전체를 영어로 번역해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 전체가 영어로 치환
- **검증 포인트**: 한국어 잔존 0건 · 문단·목록 구조 유지 · 의미 보존 · 부분만 번역되면 `FAIL`(누락 note)
