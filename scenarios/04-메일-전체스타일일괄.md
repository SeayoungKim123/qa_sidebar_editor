# 시나리오: 메일 AI 사이드패널 — 본문 전체 스타일 일괄 변경

## 메타 정보
- **ID**: SCN-04
- **우선순위**: P1
- **목적**: 선택 없이 **본문 전체에 작용하는 전역 스타일 명령**(전체 글자 크기·색·글꼴·정렬·줄간격, 역할별 일괄 서식, 복합 테마 적용, 서식 초기화)을 AI 가 **모든 문단·요소에 누락 없이 일관 적용**하는지, 그리고 **텍스트 내용과 기존 구조(표·목록·가로선)를 보존**하는지 검증. 부분 적용(SCN-02)·블록 요소 삽입(SCN-03)과 달리 **"한 번의 명령으로 전체를 한꺼번에 재서식"** 하는 전역성·일관성이 핵심.
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 메일 → 메일 쓰기 진입, 상단 **보라색 AI 아이콘**으로 AI 사이드패널 노출
  - **여러 문단 + 제목/소제목 + 나열 항목(표·목록) 등 서식 요소가 섞인 메일** 준비 (SCN-01 산출물 또는 SCN-03 산출물 재사용 권장 — 일괄 적용의 누락·구조 보존을 보려면 다양한 요소가 있어야 함)
- **검증 규칙**: 본문 직접 조작 **금지**. 프롬프트만 사용. **AI 는 본문만 편집**. **텍스트(글자) 내용은 그대로 두고 서식만 바뀌어야 함** — 단어 변경·문장 재작성 시 `FAIL`. 전역 명령이 **일부 문단만 적용하고 나머지를 누락하면 `FAIL` + 누락 항목 note**. 표·목록·가로선 등 기존 구조가 깨지면 `FAIL`.

---

## 사용자 흐름

선택 없이 전송하는 전역 명령으로 메일 전체를 한 번에 재서식한다. 서식은 누적되며, 뒤 명령이 앞 결과 위에 덮인다. 선행 본문이 없으면 후속 TC 는 `BLOCKED`.

1. **전체 글자 크기** — 본문 전체 크기 일괄 조정
2. **전체 글자색** — 본문 전체 색 통일
3. **전체 글꼴** — 본문 전체 폰트 변경
4. **역할별 일괄** — 제목/본문 역할에 따라 차등 일괄 서식
5. **전체 정렬** — 본문 전체 정렬 통일
6. **전체 줄간격** — 가독성 위한 간격 일괄 조정
7. **복합 테마 일괄** — 여러 스타일 속성 한 번에 (비즈니스 서식)
8. **전체 서식 초기화** — 적용된 서식 일괄 제거

## 테스트 케이스

### TC-01: 전체 글자 크기 일괄 변경
- **입력**:
  - 프롬프트: `"본문 전체 글자 크기를 한 단계 키워줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 모든 문단의 글자 크기가 일괄 증가
- **검증 포인트**: 전 문단 크기 증가·**한 문단도 빠지지 않음**(누락 시 `FAIL`+note) · 텍스트 내용 불변 · 표/목록 내 텍스트도 함께 반영

### TC-02: 전체 글자색 통일
- **입력**:
  - 프롬프트: `"본문 전체 글자색을 진한 회색으로 통일해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 모든 텍스트가 동일한 진회색으로 변경
- **검증 포인트**: 전체 글자색 일관 적용·색 편차 없음 · 누락 문단 없음 · 내용 불변 · 표/목록 텍스트 포함

### TC-03: 전체 글꼴 변경
- **입력**:
  - 프롬프트: `"본문 전체 글꼴을 돋움체(고딕 계열)로 바꿔줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 전체 폰트가 지정 글꼴로 일괄 변경
- **검증 포인트**: 전 문단 글꼴 일괄 적용 · 일부 문단 원래 글꼴 잔존 시 `FAIL`+note · 내용 불변 · (에디터가 글꼴 지정 미지원이면 동작·안내 note 기록)

### TC-04: 역할별 스타일 일괄 적용
- **입력**:
  - 프롬프트: `"제목과 소제목은 남색 굵게 크게, 본문은 검정 기본 크기로 — 메일 전체를 한 번에 정리해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 제목/소제목과 본문이 역할에 따라 **서로 다른 스타일로 동시 일괄** 적용
- **검증 포인트**: 제목류·본문류 구분 인식 · 각 역할 스타일 일관 적용 · 본문이 제목 스타일로 잘못 적용되지 않음 · 내용 불변

### TC-05: 전체 정렬 통일
- **입력**:
  - 프롬프트: `"본문 전체를 양쪽 정렬로 맞춰줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 모든 문단 정렬이 양쪽 정렬로 통일
- **검증 포인트**: 전 문단 정렬 일괄 적용 · 누락 문단 없음 · 표/목록 구조 유지 · 내용 불변

### TC-06: 전체 줄간격(문단 간격) 조정
- **입력**:
  - 프롬프트: `"본문 전체 줄 간격을 넓혀서 읽기 편하게 만들어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 전체 줄간격/문단 간격이 일괄 확대
- **검증 포인트**: 전체 간격 일관 적용 · 텍스트 내용·구조 보존 · (미지원 시 동작·안내 note)

### TC-07: 복합 테마 일괄 적용 (비즈니스 서식)
- **입력**:
  - 프롬프트: `"메일 전체를 깔끔한 비즈니스 서식으로 한 번에 정리해줘 — 제목 강조, 본문 가독성, 정렬·간격 일관되게"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 글자 크기·색·정렬·간격 등 **여러 스타일 속성이 한 번의 명령으로 동시 일괄** 적용되어 통일된 서식 완성
- **검증 포인트**: 복수 스타일 속성 동시 적용 · 전체 일관성 향상 · **텍스트 내용 손실 0** · 표·가로선·목록 기존 구조 보존 · 과도한 내용 재작성 없음

### TC-08: 전체 서식 초기화
- **입력**:
  - (앞 TC 들로 서식이 적용된 상태에서) 프롬프트: `"본문에 적용된 서식을 모두 지우고 기본 서식으로 되돌려줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 색·크기·굵게·정렬 등 적용 서식이 일괄 제거되고 기본(plain) 서식으로 복귀
- **검증 포인트**: 서식 속성 전반 제거됨 · **텍스트 내용은 그대로 보존**(글자 삭제 시 `FAIL`) · 표/목록 등 구조 처리 방식 note 기록
