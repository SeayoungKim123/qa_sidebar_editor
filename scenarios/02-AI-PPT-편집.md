# 시나리오: AI PPT 슬라이드 편집

## 메타 정보
- **ID**: SCN-02
- **우선순위**: P0
- **목적**: ONLYOFFICE 프레젠테이션 편집기에서 우측 AI 사이드패널 채팅창에 자연어 명령을 입력했을 때, 슬라이드가 명령 의도대로 정확히 편집되는지 검증
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 우측 AI 어시스턴트 사이드패널 노출, 모델 `GPT 4.1` 선택
  - 테스트용 PPTX 1개 열림 (최소 3장 슬라이드, 빈 본문 슬라이드 1장 포함)
  - 편집 모드 활성화

---

## 사용자 흐름

1. PPTX 열기 → 편집 모드
2. 좌측 슬라이드 목록에서 대상 슬라이드 선택
3. (필요 시) 슬라이드 내 텍스트 박스/도형 선택
4. 우측 AI 채팅창에 자연어 명령 입력 → 전송
5. 슬라이드/내용/서식 변경 확인
6. 저장 → 재오픈하여 영속 확인

---

## 테스트 케이스

### TC-01: 슬라이드 추가 — "표 슬라이드 1장 추가해줘"
- **입력**:
  - 현재 마지막 슬라이드 선택 상태
  - 프롬프트: `"분기별 매출표(1Q~4Q, 매출액) 슬라이드 1장 추가해줘"`
- **조작 순서**:
  1. 마지막 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 슬라이드 1장 새로 추가 (총 개수 +1)
  - 새 슬라이드에 2열 5행 표(헤더 + 1Q~4Q)
  - 매출액 컬럼에 더미 숫자 채워짐
- **검증 포인트**:
  - 좌측 슬라이드 패널에 새 썸네일 노출
  - 표가 PPTX 네이티브 표 객체 (편집 가능)
  - 기존 슬라이드 변형 없음

### TC-02: 글자 크기 조정 — "제목 36pt 로 키워줘"
- **입력**:
  - 슬라이드의 제목 텍스트 박스 선택
  - 프롬프트: `"선택한 제목 글자 크기를 36pt로 키우고 굵게 해줘"`
- **조작 순서**:
  1. 제목 박스 클릭
  2. 프롬프트 전송
- **기대 결과**:
  - 제목 폰트 크기 36pt
  - Bold 적용
- **검증 포인트**:
  - 상단 폰트 크기 표시 `36`
  - Bold 버튼 활성
  - 본문 텍스트 박스는 변경 없음

### TC-03: 내용 작성 — "회사 소개 슬라이드 3장 만들어줘"
- **입력**:
  - 빈 새 PPTX 또는 1번 슬라이드 다음에 커서
  - 프롬프트: `"가비아 IT 회사 소개 슬라이드 3장 만들어줘. 1)표지 2)사업분야 3)비전. 각 슬라이드 본문은 글머리 기호 3개"`
- **조작 순서**:
  1. 1번 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 3개 슬라이드 추가
  - 각 슬라이드 제목이 표지/사업분야/비전
  - 사업분야/비전 슬라이드 본문에 글머리 기호 3개
- **검증 포인트**:
  - 슬라이드 순서가 의도대로 (표지 → 사업분야 → 비전)
  - 본문 글머리 기호가 PPTX bullet 스타일
  - 한글 텍스트 정상 노출 (깨짐 없음)

### TC-04: 형식 맞추기 — "본문 가운데 정렬 + 색상 변경"
- **입력**:
  - 슬라이드 본문 텍스트 박스 선택
  - 프롬프트: `"선택한 본문을 가운데 정렬하고 글자 색을 파랑(#1E66F5)으로 바꿔줘"`
- **조작 순서**:
  1. 본문 박스 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 텍스트 가운데 정렬
  - 글자 색이 지정 파랑색
- **검증 포인트**:
  - 정렬 아이콘 가운데로 표기
  - 글자 색 미리보기 박스가 지정 색
  - 다른 슬라이드/박스 영향 없음

### TC-05: 도형/항목 추가 — "글머리 기호 3개 추가"
- **입력**:
  - 빈 본문 영역 슬라이드 선택
  - 프롬프트: `"이 슬라이드 본문에 'AI 편집', '협업', '클라우드' 3개 항목을 글머리 기호로 추가해줘"`
- **조작 순서**:
  1. 빈 본문 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 본문 영역에 3개 글머리 항목 삽입
  - 각 항목 텍스트가 정확히 일치
- **검증 포인트**:
  - bullet list 스타일 (텍스트 `•` 수동 삽입 아님)
  - 항목 추가 시 자동으로 같은 스타일 계승

### TC-06: 슬라이드 통합 편집 — "전체 슬라이드 제목 폰트 통일"
- **입력**: 프롬프트 `"모든 슬라이드 제목을 'Pretendard' 폰트, 32pt, 굵게로 통일해줘"`
- **조작 순서**: 어떤 슬라이드든 선택 후 전송
- **기대 결과**:
  - 모든 슬라이드 제목이 동일 폰트/크기/굵기
- **검증 포인트**:
  - 각 슬라이드를 순회하며 제목 속성 확인
  - 본문 텍스트는 영향 없음
  - 한 슬라이드만 적용된 경우 `FAIL`

### TC-07: 디자인 — 테마/색상 팔레트 변경
- **입력**:
  - 슬라이드 3장 이상 PPTX
  - 프롬프트: `"전체 슬라이드 디자인 테마를 모던 비즈니스 스타일로 바꿔줘. 메인 색상은 짙은 남색(#0F2A5F), 강조색은 주황(#FF8A3D), 배경은 흰색, 제목은 굵은 산세리프"`
- **조작 순서**: 어떤 슬라이드든 선택 후 전송
- **기대 결과**:
  - 모든 슬라이드 배경/제목 색상이 지정 팔레트로 변경
  - 강조 요소(언더라인·도형 등)에 주황 적용
- **검증 포인트**:
  - 슬라이드 순회 시 색상 일관성
  - 텍스트 가독성 유지 (배경/글자 대비)
  - 슬라이드 콘텐츠 텍스트 변형 없음

### TC-08: 디자인 — 표지 슬라이드 디자인
- **입력**:
  - 1번 슬라이드 선택 (빈 슬라이드 또는 기본 제목 슬라이드)
  - 프롬프트: `"표지 슬라이드를 디자인해줘. 제목 'AI 문서 편집 데모', 부제 '가비아 AI팀 2026', 배경은 짙은 남색 그라데이션, 제목은 흰색 굵게 48pt, 좌측 하단에 작은 강조 도형 추가"`
- **조작 순서**:
  1. 1번 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 배경 그라데이션 (짙은 남색 계열)
  - 제목/부제 텍스트 위치·서식 적용
  - 좌측 하단에 도형 1개
- **검증 포인트**:
  - 제목 48pt 흰색 굵게
  - 배경이 단색이 아닌 그라데이션
  - 도형이 좌측 하단 영역에 위치
  - 다른 슬라이드 변경 없음

### TC-09: 디자인 — 강조 도형/박스 추가
- **입력**:
  - 본문 슬라이드 선택
  - 프롬프트: `"이 슬라이드 우측 상단에 'NEW' 라벨이 들어간 빨간색 둥근 사각형 강조 도형을 추가해줘"`
- **조작 순서**:
  1. 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**:
  - 우측 상단에 둥근 사각형 도형 1개
  - 내부 텍스트 `NEW`, 도형 색 빨강
- **검증 포인트**:
  - 도형이 클릭/이동 가능한 네이티브 도형 객체
  - 도형 텍스트가 `NEW` 정확히 일치
  - 본문/제목 텍스트 변형 없음

### TC-10: 비대상 명령 — "이 슬라이드를 영상으로 만들어줘"
- **입력**: 프롬프트 `"이 슬라이드를 영상으로 변환해줘"`
- **조작 순서**: 프롬프트 전송
- **기대 결과**:
  - 불가 안내 또는 대안 제시
  - 슬라이드에 의도치 않은 변경 없음
- **검증 포인트**:
  - 슬라이드 변경 0건
  - 명시적 거절/안내 노출
