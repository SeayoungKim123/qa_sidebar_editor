# 시나리오: PPT 실사용 흐름 — 백지에서 발표 덱 만들고 다듬기

## 메타 정보
- **ID**: SCN-02
- **우선순위**: P0
- **목적**: 실제 사용자가 발표 덱을 **빈 프레젠테이션에서 시작해 단계적으로 완성**하는 흐름을 따라가며, ONLYOFFICE 우측 AI 사이드패널이 PPT 의 특성(슬라이드 단위·레이아웃·테마/색상·도형)에 맞게 명령을 정확히 수행하는지 검증
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 파일 행 호버 → **두 번째 "미리보기 (MCP ver)" 플라스크 아이콘** 클릭 → Hiworks AI 탭 진입
  - 우측 AI 어시스턴트 사이드패널 노출, 모델 `GPT 4.1` 선택
  - **빈 PPTX 1개** 열림 (슬라이드 1장, 본문 비어 있음), 편집 모드 활성화
- **검증 규칙**: 슬라이드에 직접 타이핑·서식 조작 **금지**. 오직 AI 채팅창에 프롬프트만 전송하고, AI 가 슬라이드를 편집하는지를 관찰·검증한다.

---

## 사용자 흐름

이 시나리오는 **하나의 덱이 단계적으로 진화**한다. 앞 단계 산출물을 뒤 단계가 수정하므로 TC 는 순서대로 진행하며, 선행 TC 가 실패해 대상이 없으면 후속 TC 는 `BLOCKED`.

1. **1단계 (백지)** — 빈 덱에 표지·본문·데이터 슬라이드를 AI로 생성
2. **2단계 (개별)** — 특정 슬라이드의 제목/본문/도형을 콕 집어 수정
3. **3단계 (일괄)** — 덱 전체 테마·제목 폰트·표지 디자인을 한 번에 변경
4. 각 단계 후 좌측 슬라이드 패널·화면 반영 확인, 마지막에 저장 → 재오픈하여 영속 확인

---

## 테스트 케이스

### 1단계 · 백지에서 작성

#### TC-01: 표지 슬라이드 작성
- **입력**:
  - 빈 1번 슬라이드 선택
  - 프롬프트: `"표지 슬라이드를 만들어줘. 제목 'AI 문서편집 데모', 부제 '가비아 AI팀 2026'"`
- **조작 순서**:
  1. 좌측에서 1번 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**: 1번 슬라이드에 제목/부제 텍스트 배치
- **검증 포인트**: 제목·부제 텍스트 정확히 일치 · 한글 깨짐 없음

#### TC-02: 본문 슬라이드 다수 생성
- **입력**:
  - 프롬프트: `"내용 슬라이드 3장 추가해줘. 1)배경 2)핵심기능 3)기대효과. 각 슬라이드 본문은 글머리 기호 3개"`
- **조작 순서**:
  1. 1번 슬라이드(표지) 선택
  2. 프롬프트 전송
- **기대 결과**: 슬라이드 3장 추가(총 4장), 각 제목 배경/핵심기능/기대효과, 본문 글머리 3개
- **검증 포인트**: 좌측 패널 썸네일 3개 추가 · 슬라이드 순서 정확 · 표지 슬라이드 변형 없음

#### TC-03: 데이터 슬라이드 추가
- **입력**:
  - 프롬프트: `"분기별 매출표(1Q~4Q, 매출액) 슬라이드 1장 추가해줘. 매출액은 더미 숫자"`
- **조작 순서**:
  1. 마지막 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**: 슬라이드 1장 추가(총 5장), 표(헤더 + 1Q~4Q) + 더미 매출액
- **검증 포인트**: 표 셀 클릭 시 편집 가능 · 기존 슬라이드 변형 없음

### 2단계 · 개별 요소 수정 (1단계 산출물 대상, 선행 의존)

#### TC-04: 특정 슬라이드 제목 수정
- **입력**:
  - '핵심기능' 슬라이드의 제목 텍스트 박스 선택
  - 프롬프트: `"선택한 제목 글자 크기를 36pt로 키우고 굵게 해줘"`
- **조작 순서**:
  1. '핵심기능' 슬라이드 → 제목 박스 클릭 (선택만)
  2. 프롬프트 전송
- **기대 결과**: 해당 제목만 36pt + 굵게
- **검증 포인트**: 폰트 크기 `36` 표기 · 본문 박스/다른 슬라이드 무변동

#### TC-05: 특정 본문 서식
- **입력**:
  - '기대효과' 슬라이드 본문 박스 선택
  - 프롬프트: `"선택한 본문을 가운데 정렬하고 글자색을 파랑(#1E66F5)으로 바꿔줘"`
- **조작 순서**:
  1. '기대효과' 슬라이드 → 본문 박스 클릭
  2. 프롬프트 전송
- **기대 결과**: 본문 가운데 정렬 + 파랑
- **검증 포인트**: 정렬 아이콘 가운데 · 글자색 지정 파랑 · 다른 슬라이드/박스 영향 없음

#### TC-06: 강조 도형 추가
- **입력**:
  - '핵심기능' 슬라이드 선택
  - 프롬프트: `"이 슬라이드 우측 상단에 'NEW' 라벨이 들어간 빨간색 둥근 사각형 강조 도형을 추가해줘"`
- **조작 순서**:
  1. '핵심기능' 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**: 우측 상단 둥근 사각형 1개, 텍스트 `NEW`, 빨강
- **검증 포인트**: 도형 화면 표시 · 텍스트 `NEW` 정확 · 제목/본문 변형 없음

### 3단계 · 여러 요소 일괄 수정 (전체 재서식)

#### TC-07: 전체 테마/색상 팔레트 변경
- **입력**:
  - 프롬프트: `"전체 슬라이드 디자인 테마를 모던 비즈니스 스타일로 바꿔줘. 메인 색상 짙은 남색(#0F2A5F), 강조색 주황(#FF8A3D), 배경 흰색, 제목은 굵은 산세리프"`
- **조작 순서**: 아무 슬라이드 선택 후 전송
- **기대 결과**: 모든 슬라이드 배경/제목 색상이 지정 팔레트로, 강조 요소에 주황
- **검증 포인트**: 슬라이드 순회 시 색상 일관성 · 텍스트 가독성(대비) 유지 · 콘텐츠 텍스트 변형 없음 · 일부만 적용되면 `FAIL`

#### TC-08: 제목 폰트 일괄 통일
- **입력**:
  - 프롬프트: `"모든 슬라이드 제목을 32pt, 굵게로 통일해줘"`
- **조작 순서**: 아무 슬라이드 선택 후 전송
- **기대 결과**: 모든 슬라이드 제목 32pt + 굵게
- **검증 포인트**: 각 슬라이드 순회 제목 속성 확인 · TC-04 의 36pt 제목이 32pt로 덮이는지 확인 후 note 기록 · 본문 영향 없음 · 한 장만 적용되면 `FAIL`

#### TC-09: 표지 슬라이드 디자인
- **입력**:
  - 프롬프트: `"표지 슬라이드 배경을 짙은 남색 그라데이션으로 하고, 제목을 흰색 굵게 48pt로 키워줘. 좌측 하단에 작은 강조 도형 추가"`
- **조작 순서**:
  1. 1번 슬라이드(표지) 선택
  2. 프롬프트 전송
- **기대 결과**: 배경 남색 그라데이션, 제목 흰색 48pt 굵게, 좌측 하단 도형 1개
- **검증 포인트**: 배경이 단색 아닌 그라데이션 · 제목 48pt 흰색 · 도형 좌측 하단 위치 · 다른 슬라이드 변경 없음
