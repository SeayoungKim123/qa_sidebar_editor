# 시나리오: 메일 AI 사이드패널 — 컨텐츠 일부 요소 변경하기

## 메타 정보
- **ID**: SCN-02
- **우선순위**: P0
- **목적**: 완성된 메일 본문에서 **특정 요소(한 문단·한 표현·한 문장)만 콕 집어 수정**하라는 요청을 AI 가 정확히 좁혀 수행하는지, 그리고 **지정하지 않은 나머지 본문은 무변동**으로 보존하는지 검증
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 메일 → 메일 쓰기 진입, 상단 **보라색 AI 아이콘**으로 AI 사이드패널 노출
  - **본문에 여러 문단으로 구성된 메일이 채워져 있음** (SCN-01 산출물 재사용 또는 동등한 더미 메일)
- **검증 규칙**: 본문 직접 타이핑·서식 조작 **금지**. AI 채팅창 프롬프트만 사용. **AI 는 본문만 편집**. 의도 외 변경(번짐) 발생 시 `FAIL` + note 기록.

---

## 사용자 흐름

여러 문단으로 채워진 메일을 대상으로, 부분 선택 또는 명시적 지정을 통해 한 요소씩만 바꾼다. 선행 TC 의 본문이 없으면 후속 TC 는 `BLOCKED`.

1. **부분 톤 변환** — 특정 문단만 선택해 톤 변경
2. **표현 치환** — 본문 전반의 특정 단어만 다른 표현으로 교체
3. **부분 요약** — 한 문단만 짧게 줄임
4. **부분 교정** — 한 문장의 맞춤법만 교정

## 테스트 케이스

### TC-01: 특정 문단 톤 변환
- **입력**:
  - 본문 중 한 문단 드래그 선택
  - 프롬프트: `"선택한 문단만 더 공손하고 정중한 톤으로 바꿔줘"`
- **조작 순서**:
  1. 대상 문단 드래그 선택 (선택만, 직접 수정 금지)
  2. 프롬프트 전송
- **기대 결과**: 선택 문단만 정중한 톤으로 재작성
- **검증 포인트**: 선택 문단의 의미 유지 · 톤 상승 체감 · 나머지 문단 글자 무변동

### TC-02: 특정 표현 일괄 치환
- **입력**:
  - 프롬프트: `"본문에 있는 '할인'이라는 단어를 모두 '특별 혜택'으로 바꿔줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문의 '할인' → '특별 혜택' 전부 치환
- **검증 포인트**: '할인' 잔존 0건 · 문장 구조는 자연스럽게 유지 · 다른 단어 변형 없음

### TC-03: 한 문단만 요약
- **입력**:
  - 가장 긴 문단 드래그 선택
  - 프롬프트: `"선택한 문단만 한 문장으로 짧게 줄여줘"`
- **조작 순서**:
  1. 대상 문단 선택
  2. 프롬프트 전송
- **기대 결과**: 선택 문단이 한 문장으로 축약, 나머지는 그대로
- **검증 포인트**: 해당 문단 길이 감소 · 핵심 의미 보존 · 다른 문단 길이 무변동

### TC-04: 한 문장 맞춤법 교정
- **입력**:
  - 오타/띄어쓰기 오류가 있는 한 문장 선택 (없으면 AI로 오타 포함 문장 한 줄 추가 후 진행)
  - 프롬프트: `"이 문장만 맞춤법과 띄어쓰기를 고쳐줘"`
- **조작 순서**:
  1. 대상 문장 선택
  2. 프롬프트 전송
- **기대 결과**: 해당 문장만 교정, 의미·어조 유지
- **검증 포인트**: 오타 해소 · 선택 문장 외 본문 무변동 · 새 내용 추가 없음
