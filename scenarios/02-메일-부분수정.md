# 시나리오: 메일 AI 사이드패널 — 선택 요소 스타일 편집 (부분·인라인 서식)

## 메타 정보
- **ID**: SCN-02
- **우선순위**: P0
- **목적**: 완성된 메일 본문에서 **특정 요소(문단·구간·문장)만 콕 집어 인라인 문자 서식**(글자 크기·글자색·굵게·기울임·밑줄·형광펜 강조)을 적용하라는 요청을, AI 가 **지정 범위에만 정확히** 적용하고 나머지 본문은 내용·서식 모두 **무변동**으로 보존하는지 검증. **텍스트 내용 변경이 아니라 서식(스타일) 적용이 검증 대상.**
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 메일 → 메일 쓰기 진입, 상단 **보라색 AI 아이콘**으로 AI 사이드패널 노출
  - **본문에 여러 문단으로 구성된 메일이 채워져 있음** (SCN-01 산출물 재사용 또는 동등한 더미 메일)
- **검증 규칙**: 본문 직접 타이핑·서식 조작 **금지**. AI 채팅창 프롬프트만 사용. **AI 는 본문만 편집**. **글자(텍스트)는 그대로 두고 서식만 바뀌어야 함** — 단어가 치환되거나 문장이 재작성되면 `FAIL`. 지정 범위 밖 서식/내용 변동(번짐) 발생 시 `FAIL` + note 기록.

## 사용자 흐름

여러 문단으로 채워진 메일을 대상으로, 부분 선택 또는 명시적 지정을 통해 한 요소씩만 서식을 입힌다. 선행 TC 의 본문이 없으면 후속 TC 는 `BLOCKED`. 각 TC 는 직전 서식 위에 누적될 수 있음(상호 충돌 시 note).

1. **부분 글자 크기** — 선택 문단만 크게
2. **부분 글자색** — 선택 텍스트 색 변경
3. **부분 강조** — 굵게 + 형광펜
4. **부분 밑줄·기울임** — 지정 문장만

## 테스트 케이스

### TC-01: 선택 문단 글자 크기 키우기
- **입력**:
  - 본문 중 한 문단 드래그 선택
  - 프롬프트: `"선택한 문단의 글자 크기를 더 크게 키워줘"`
- **조작 순서**:
  1. 대상 문단 드래그 선택 (선택만, 직접 수정 금지)
  2. 프롬프트 전송
- **기대 결과**: 선택 문단만 글자 크기가 커짐
- **검증 포인트**: 선택 문단 글자 크기 증가 · **텍스트(글자) 내용 불변** · 나머지 문단 크기 무변동

### TC-02: 선택 텍스트 글자색 변경
- **입력**:
  - 강조할 핵심 구절(단어·문장) 드래그 선택
  - 프롬프트: `"선택한 부분 글자색을 빨간색으로 바꿔줘"`
- **조작 순서**:
  1. 대상 구간 드래그 선택
  2. 프롬프트 전송
- **기대 결과**: 선택 구간만 빨간색 글자로 변경
- **검증 포인트**: 선택 구간 글자색 적용 · 텍스트 내용 불변 · 비선택 부분 색 무변동

### TC-03: 선택 구간 굵게 + 형광펜 강조
- **입력**:
  - 중요 문장 드래그 선택
  - 프롬프트: `"이 문장을 굵게 하고 노란 형광펜으로 강조해줘"`
- **조작 순서**:
  1. 대상 문장 선택
  2. 프롬프트 전송
- **기대 결과**: 선택 문장에 굵게(bold) + 배경 하이라이트(형광펜) 동시 적용
- **검증 포인트**: 굵게·하이라이트 둘 다 적용됨 · 내용 불변 · 적용 범위가 선택 문장과 정확히 일치

### TC-04: 지정 문장 밑줄·기울임
- **입력**:
  - 한 문장 드래그 선택
  - 프롬프트: `"이 문장에 밑줄을 긋고 기울임체로 만들어줘"`
- **조작 순서**:
  1. 대상 문장 선택
  2. 프롬프트 전송
- **기대 결과**: 선택 문장에 밑줄(underline) + 기울임(italic) 적용
- **검증 포인트**: 밑줄·기울임 적용 · 다른 문장 서식 무변동 · 내용 불변
