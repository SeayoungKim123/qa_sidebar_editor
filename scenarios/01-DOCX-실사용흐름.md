# 시나리오: DOCX 실사용 흐름 — 백지에서 작성하고 다듬기

## 메타 정보
- **ID**: SCN-01
- **우선순위**: P0
- **목적**: 실제 사용자가 사업계획서를 **빈 문서에서 시작해 단계적으로 완성**하는 흐름을 따라가며, ONLYOFFICE 우측 AI 사이드패널이 DOCX 의 특성(흐르는 텍스트·단락/제목 스타일·페이지 흐름)에 맞게 명령을 정확히 수행하는지 검증
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 파일 행 호버 → **두 번째 "미리보기 (MCP ver)" 플라스크 아이콘** 클릭 → Hiworks AI 탭 진입
  - 우측 AI 어시스턴트 사이드패널 노출, 모델 `GPT 5.4` 선택
  - **빈 DOCX 1개** 열림 (본문 없음), 편집 모드 활성화
- **검증 규칙**: 본문에 직접 타이핑·서식 조작 **금지**. 오직 AI 채팅창에 프롬프트만 전송하고, AI 가 문서를 편집하는지를 관찰·검증한다.

---

## 사용자 흐름

이 시나리오는 **하나의 문서가 단계적으로 진화**한다. 앞 단계 산출물을 뒤 단계가 수정하므로 TC 는 순서대로 진행하며, 선행 TC 가 실패해 대상이 없으면 후속 TC 는 `BLOCKED`.

1. **1단계 (백지)** — 빈 문서에 개요·섹션·표를 AI로 생성
2. **2단계 (개별)** — 1단계에서 만든 개별 요소(특정 단락/제목/표)를 콕 집어 수정
3. **3단계 (일괄)** — 문서 전체 요소를 한 번에 재서식 (스타일 통일·표지·본문 정리)
4. 각 단계 후 화면 반영 확인, 마지막에 저장 → 재오픈하여 영속 확인

## 테스트 케이스

### 1단계 · 백지에서 작성

#### TC-01: 개요 단락 작성
- **입력**:
  - 빈 문서, 본문 맨 위 커서
  - 프롬프트: `"가비아 2026 사업계획서 개요를 3문단으로 작성해줘. 회사 소개, 올해 방향성, 기대효과 순서로"`
- **조작 순서**:
  1. 본문 맨 위 클릭 (커서 위치만 지정, 직접 입력 금지)
  2. 채팅창에 프롬프트 전송 → 응답 대기 (필요 시 "본문에 삽입")
- **기대 결과**: 커서 위치에 한국어 3개 단락 삽입, 각 단락이 소개/방향성/기대효과 주제
- **검증 포인트**: 총 글자 수 200자 이상 · 단락 구분 명확 · 깨짐 없음

#### TC-02: 섹션 구조 생성
- **입력**:
  - TC-01 개요 아래 커서
  - 프롬프트: `"개요 다음에 '1. 시장환경', '2. 사업전략', '3. 추진일정' 세 섹션을 만들어줘. 각 섹션은 제목 한 줄 + 본문 2문단"`
- **조작 순서**:
  1. 개요 단락 끝에 커서
  2. 프롬프트 전송
- **기대 결과**: 제목 3개(1./2./3.) + 각 본문 2문단이 순서대로 삽입
- **검증 포인트**: 제목과 본문이 시각적으로 구분됨 · 섹션 순서 정확 · TC-01 개요 단락 변형 없음

#### TC-03: 표 삽입
- **입력**:
  - '3. 추진일정' 섹션 아래 커서
  - 프롬프트: `"추진일정 섹션 아래에 분기별 일정표를 만들어줘. 4행 3열, 헤더는 분기/과제/담당, 1Q~3Q 더미 데이터 채워줘"`
- **조작 순서**:
  1. 추진일정 본문 끝에 커서
  2. 프롬프트 전송
- **기대 결과**: 4행 3열 표 삽입, 첫 행 헤더(분기/과제/담당), 아래 3행 더미
- **검증 포인트**: 표 셀 클릭 시 편집 가능 · 저장 후 재오픈 시 표 구조 유지 · 다른 섹션 변형 없음

### 2단계 · 개별 요소 수정 (1단계 산출물 대상, 선행 의존)

#### TC-04: 특정 단락 강조
- **입력**:
  - 개요 첫 문단 드래그 선택
  - 프롬프트: `"개요 첫 문단 글자 크기를 14pt로 키우고 굵게 해줘"`
- **조작 순서**:
  1. 개요 첫 문단 드래그 선택 (선택만, 서식 조작 금지)
  2. 프롬프트 전송
- **기대 결과**: 선택 문단만 14pt + 굵게
- **검증 포인트**: 폰트 크기 입력란에 `14` · 굵게 표시 · 나머지 단락 11pt·일반 유지 (의도 외 변경 없음)

#### TC-05: 특정 제목만 서식
- **입력**:
  - 프롬프트: `"'2. 사업전략' 제목만 글자색 파랑(#1E66F5)으로 바꾸고 가운데 정렬해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: '2. 사업전략' 줄만 파랑 + 가운데 정렬
- **검증 포인트**: 1./3. 제목은 색·정렬 변동 없음 · 본문 영향 없음 · 다른 줄에 색 번짐 없음

#### TC-06: 표 부분 수정
- **입력**:
  - 프롬프트: `"일정표 헤더 행만 굵게 + 배경색 회색으로 해줘"`
- **조작 순서**:
  1. 일정표 클릭 (선택)
  2. 프롬프트 전송
- **기대 결과**: 헤더 행(1행) 셀만 굵게 + 배경 회색
- **검증 포인트**: 데이터 행(2~4행)은 무변동 · 표 외부 본문 영향 없음

### 3단계 · 여러 요소 일괄 수정 (전체 재서식)

#### TC-07: 섹션 제목 스타일 일괄 통일
- **입력**:
  - 프롬프트: `"문서의 모든 섹션 제목(1./2./3.)을 '제목 2' 스타일로 통일하고, 색은 짙은 남색으로 해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 3개 섹션 제목 모두 '제목 2' 스타일 + 짙은 남색 일관 적용
- **검증 포인트**: 탐색 창/스타일 표시에 `제목 2` 인식 · TC-05 에서 바꾼 색이 일괄 색으로 덮이는지 확인 · 본문 단락 영향 없음 · 하나만 적용되면 `FAIL` (누락 항목 note 기록)

#### TC-08: 표지 페이지 추가 + 페이지 나누기
- **입력**:
  - 프롬프트: `"맨 앞에 표지 페이지를 추가해줘. 제목 '2026 사업계획서' 36pt 굵게, 부제 '가비아 AI팀', 둘 다 가운데 정렬, 표지와 본문 사이 페이지 나누기"`
- **조작 순서**: (커서 문서 맨 앞) 프롬프트 전송
- **기대 결과**: 표지 페이지 1장 생성(제목/부제/가운데), 표지 뒤 페이지 나누기
- **검증 포인트**: 제목 36pt 굵게 · 본문 첫 단락(개요)이 2페이지에 위치 · 기존 내용 손상 없음

#### TC-09: 본문 단락 일괄 통일
- **입력**:
  - 프롬프트: `"표지를 제외한 본문 단락 전체를 글자 크기 11pt, 줄간격 1.5로 통일해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 단락 전체 11pt + 줄간격 1.5
- **검증 포인트**: 줄간격이 시각적으로 넓어짐 · 표지 제목/부제 크기는 유지(36pt 등) · TC-04 에서 키운 14pt 단락이 일괄에 덮이는지 확인 후 note 기록
