# 시나리오: Excel 객체 삽입 — 차트 다양화·표 구조 편집

## 메타 정보
- **ID**: SCN-06
- **우선순위**: P0
- **목적**: Excel 시트에서 ONLYOFFICE 우측 AI 사이드패널이 **여러 종류의 차트(막대·원형·꺾은선)를 생성하고, 표 구조(행 삽입·셀 병합)를 편집하며 수식/차트 참조가 자동 보정**되는지 검증. `05-Excel-실사용흐름`이 수식·서식 흐름을 다룬다면, 이 시나리오는 **차트·표 구조 객체 축**을 전담한다.
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 파일 행 호버 → **두 번째 "미리보기 (MCP ver)" 플라스크 아이콘** 클릭 → Hiworks AI 탭 진입
  - 우측 AI 어시스턴트 사이드패널 노출, 모델 `GPT 5.4` 선택
  - **빈 XLSX 1개** 열림 (Sheet1 비어 있음), 편집 모드 활성화
- **검증 규칙**: 셀에 직접 타이핑·서식 조작 **금지**. 오직 AI 채팅창에 프롬프트만 전송하고, AI 가 셀/수식/차트를 편집하는지를 관찰·검증한다.

---

## 사용자 흐름

이 시나리오는 **자체 셋업으로 시작해 객체를 진화**시킨다 (다른 시나리오 산출물에 의존하지 않음). TC 는 순서대로 진행하며, 선행 TC 가 실패해 대상이 없으면 후속 TC 는 `BLOCKED`.

1. **셋업** — 빈 시트에 매출표 + 총합 수식 생성
2. **차트 다양화** — 막대·원형·꺾은선 차트 각각 생성
3. **차트 디자인** — 차트 색·축·격자 수정
4. **표 구조 편집** — 행 삽입 + 셀 병합, 수식·차트 참조 보정 확인
5. 마지막에 저장 → 재오픈하여 객체 영속 확인

## 테스트 케이스

### 셋업 · 매출표 + 수식

#### TC-01: 매출표 + 총합 수식 생성
- **입력**:
  - Sheet1 빈 상태, A1 선택
  - 프롬프트: `"A1부터 직원 3명의 1~3월 매출표를 만들어줘. 헤더는 이름/1월/2월/3월, 매출 더미 숫자. E열에 '총합'을 SUM 수식으로 추가"`
- **조작 순서**:
  1. A1 클릭 (위치만 지정, 직접 입력 금지)
  2. 프롬프트 전송
- **기대 결과**: A1:D1 헤더 + A2:D4 직원 3명 데이터 + E열 총합(`=SUM(B2:D2)` 형태)
- **검증 포인트**: 월별 셀 숫자 타입 · E2 클릭 시 SUM 수식 표시(텍스트 아님) · 직원별 합과 일치

### 차트 다양화

#### TC-02: 막대 차트 생성
- **입력**:
  - 프롬프트: `"직원별 1~3월 매출 데이터로 막대 차트를 만들어줘. 제목 '1분기 매출', 가로축 직원, 세로축 매출액"`
- **조작 순서**:
  1. 데이터 범위(A1:D4) 드래그 선택
  2. 프롬프트 전송
- **기대 결과**: 막대 차트 1개 삽입, 제목 '1분기 매출', 직원별 월 매출 막대
- **검증 포인트**: 차트 유형 막대 · 데이터 변경 시 막대 높이 자동 갱신 · 제목 정확

#### TC-03: 원형 차트 생성
- **입력**:
  - 프롬프트: `"각 직원의 총합(E열) 비중을 보여주는 원형 차트를 추가해줘. 제목 '직원별 매출 비중'"`
- **조작 순서**:
  1. 이름 열(A2:A4)과 총합 열(E2:E4) 선택
  2. 프롬프트 전송
- **기대 결과**: 원형 차트 1개 삽입, 제목 '직원별 매출 비중', 직원 3명 비중 조각
- **검증 포인트**: 차트 유형 원형(막대 아님) · 조각 비율이 총합 값과 비례 · TC-02 막대 차트와 별개로 공존 · 데이터 변형 없음

#### TC-04: 꺾은선 차트 생성
- **입력**:
  - 프롬프트: `"직원별 1~3월 매출 추이를 꺾은선 차트로 만들어줘. 직원별로 선 1개씩, 가로축은 월"`
- **조작 순서**:
  1. 데이터 범위(A1:D4) 선택
  2. 프롬프트 전송
- **기대 결과**: 꺾은선 차트 1개, 직원 3명 각각 선 1개, 가로축 1~3월
- **검증 포인트**: 차트 유형 꺾은선 · 선 3개(직원 수만큼) · 월별 값이 셀과 일치 · 기존 차트/데이터 무변동

### 차트 디자인

#### TC-05: 차트 디자인 수정
- **입력**:
  - TC-02 막대 차트 선택
  - 프롬프트: `"이 차트 색상을 파랑 계열로 바꾸고, 가로축 글자 크기 12pt, 격자선을 제거해줘"`
- **조작 순서**:
  1. 막대 차트 클릭
  2. 프롬프트 전송
- **기대 결과**: 막대 파랑 계열 + 가로축 라벨 12pt + 격자선 비표시
- **검증 포인트**: 세 항목 모두 반영돼야 `PASS`, 하나라도 빠지면 `FAIL`(누락 note 기록) · 차트 데이터 변형 없음

### 표 구조 편집

#### TC-06: 행 삽입 + 셀 병합 (수식·차트 참조 보정)
- **입력**:
  - 프롬프트: `"1행 위에 '1분기 매출 현황'이라는 제목 행을 추가하고, A~E 열을 하나로 병합해서 가운데 정렬해줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 최상단에 A~E 병합된 제목 행 추가, 기존 헤더/데이터는 한 행씩 아래로 이동
- **검증 포인트**: 병합 범위 A~E · 가운데 정렬 · **아래로 밀린 SUM 수식 참조가 자동 보정되어 결과값 유지**(깨지면 `FAIL`, note 기록) · **차트 데이터 참조도 유지되어 차트 정상 표시**

#### TC-07: 저장/영속 확인
- **입력**:
  - 프롬프트 없음 (저장 동작만)
- **조작 순서**:
  1. 저장 → 파일 닫기 → 재오픈
  2. 차트·표·병합 셀 확인
- **기대 결과**: 막대/원형/꺾은선 차트 3개·표·병합 행이 재오픈 후에도 모두 유지
- **검증 포인트**: **재오픈 시 차트 3개·병합 셀·SUM 수식이 전부 영속**(하나라도 사라지거나 값이 깨지면 `FAIL`, note 기록)
