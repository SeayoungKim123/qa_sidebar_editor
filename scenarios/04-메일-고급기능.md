# 시나리오: 메일 AI 사이드패널 — 미사용 추천기능·고급 동작 검증

## 메타 정보
- **ID**: SCN-04
- **우선순위**: P1
- **목적**: 앞선 시나리오(01~03)에서 다루지 않은 **추천기능 칩 직접 클릭 동작**과 메일 특화 기능(EMS 템플릿·유효성 검사·맞춤법 검사·서식 정리·요약)을 검증해, 사이드패널이 자연어 프롬프트뿐 아니라 **버튼형 추천기능**으로도 정확히 동작하는지 확인
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 메일 → 메일 쓰기 진입, 상단 **보라색 AI 아이콘**으로 AI 사이드패널 노출
  - 추천기능 칩 표시 확인 (문서 서식 정리 / 내용 요약 / 톤 변환 / 글머리 기호 정리 / EMS 메일 템플릿 / 에디터 내용 유효성 검사 / 초안 작성 / 맞춤법 검사하기 / 내용 다듬기 / 번역하기)
  - 검증용 본문이 필요한 TC 는 채워진 메일 사용 (없으면 초안 작성으로 선준비)
- **검증 규칙**: 본문 직접 조작 **금지**. 추천기능은 **칩 클릭**으로 트리거(프롬프트 타이핑 아님). **AI 는 본문만 편집**.

---

## 사용자 흐름

추천기능 칩과 메일 특화 기능을 하나씩 눌러 동작·결과를 확인한다. TC 간 독립적이나 본문 필요 TC 는 선행 준비 본문에 의존.

1. **칩 클릭 — 내용 요약** — 버튼형 트리거 동작
2. **EMS 메일 템플릿** — 템플릿 삽입/적용
3. **에디터 내용 유효성 검사** — 검사 리포트 동작
4. **맞춤법 검사하기** — 전체 맞춤법 점검
5. **문서 서식 정리** — 서식 일괄 정돈

## 테스트 케이스

### TC-01: 추천기능 칩 클릭 — 내용 요약
- **입력**:
  - 본문이 채워진 상태에서 **"내용 요약" 칩 클릭** (프롬프트 타이핑 없이)
- **조작 순서**:
  1. 사이드패널 추천기능에서 "내용 요약" 칩 클릭
  2. 응답 대기
- **기대 결과**: 본문 내용의 요약 결과 제시 (또는 요약본 삽입)
- **검증 포인트**: 칩 클릭만으로 동작 트리거됨 · 요약이 본문 핵심 반영 · 빈 본문일 땐 안내 메시지

### TC-02: EMS 메일 템플릿
- **입력**:
  - **"EMS 메일 템플릿" 칩 클릭**
- **조작 순서**:
  1. "EMS 메일 템플릿" 칩 클릭
  2. (선택지 제시 시) 템플릿 1개 선택 → 적용
- **기대 결과**: EMS 형식 메일 템플릿이 본문에 적용
- **검증 포인트**: 템플릿 구조(머리말/본문/꼬리말 등) 삽입 · 깨짐 없음 · 기존 본문 처리 방식 확인 후 note

### TC-03: 에디터 내용 유효성 검사
- **입력**:
  - 본문이 채워진 상태에서 **"에디터 내용 유효성 검사" 칩 클릭**
- **조작 순서**:
  1. "에디터 내용 유효성 검사" 칩 클릭
  2. 결과 대기
- **기대 결과**: 본문 유효성 검사 리포트 제시 (문제 항목·개선 제안 등)
- **검증 포인트**: 검사 결과가 패널에 표시됨 · 본문을 임의 변경하지 않음(리포트형) · 항목별 안내 존재

### TC-04: 맞춤법 검사하기 (전체)
- **입력**:
  - 오타 포함 본문에서 **"맞춤법 검사하기" 칩 클릭**
- **조작 순서**:
  1. "맞춤법 검사하기" 칩 클릭
  2. (교정 제안 제시 시) 적용
- **기대 결과**: 본문 전체 맞춤법/띄어쓰기 오류 검출 및 교정 제안·적용
- **검증 포인트**: 오타 검출됨 · 교정 후 의미 유지 · 정상 문장 오교정 없음

### TC-05: 문서 서식 정리
- **입력**:
  - 서식이 들쭉날쭉한 본문에서 **"문서 서식 정리" 칩 클릭**
- **조작 순서**:
  1. "문서 서식 정리" 칩 클릭
  2. 결과 대기
- **기대 결과**: 본문 서식(줄간격·정렬·불필요 공백 등) 일괄 정돈
- **검증 포인트**: 서식 일관성 향상 · 내용 텍스트 손실 없음 · 과도한 재작성 없음
