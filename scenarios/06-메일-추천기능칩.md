# 시나리오: 메일 AI 사이드패널 — 추천기능 칩 전수 검증 (버튼 트리거)

## 메타 정보
- **ID**: SCN-06
- **우선순위**: P1
- **목적**: 사이드패널 상단 **추천기능 칩**을 자연어 타이핑 없이 **버튼 클릭만으로** 트리거했을 때 각 기능이 정확히 동작하는지 전수 검증. 검증 범위는 패널 표시 순서 기준 **문서 서식 정리 → 내용 요약 → 톤 변환 → 글머리 기호 정리 → EMS 메일 템플릿 → 에디터 내용 유효성 검사** (총 6개 칩).
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 메일 → 메일 쓰기 진입, 상단 **보라색 AI 아이콘**으로 AI 사이드패널 노출
  - 추천기능 칩 표시 확인 (문서 서식 정리 / 내용 요약 / 톤 변환 / 글머리 기호 정리 / EMS 메일 템플릿 / 에디터 내용 유효성 검사 / 초안 작성 / 맞춤법 검사하기 / 내용 다듬기 / 번역하기)
  - 본문이 필요한 칩(서식 정리·요약·톤 변환·글머리·유효성)은 **여러 문단으로 채워진 메일** 준비 (SCN-01 산출물 재사용 권장). EMS 템플릿은 빈 본문에서도 진행 가능.
- **검증 규칙**: 본문 직접 조작 **금지**. 각 기능은 **칩 클릭으로 트리거**(프롬프트 타이핑 아님). **AI 는 본문만 편집**. 칩 클릭 후 옵션/선택지가 뜨면 1개 선택해 적용까지 완료. 초안 작성·내용 다듬기·번역하기 칩은 본 시나리오 범위 밖 — 해당 기능은 SCN-01(초안)·SCN-03(다듬기·번역)에서 프롬프트로 검증됨.

## 사용자 흐름

추천기능 칩을 패널 표시 순서대로 하나씩 클릭해 동작·결과를 확인한다. TC 간 독립적이나, 본문 필요 칩은 선준비된 본문에 의존(없으면 `BLOCKED`).

1. **문서 서식 정리** — 서식 일괄 정돈
2. **내용 요약** — 본문 요약
3. **톤 변환** — 어조 변경 (옵션 선택형일 수 있음)
4. **글머리 기호 정리** — 나열부 불릿화
5. **EMS 메일 템플릿** — 템플릿 삽입/적용
6. **에디터 내용 유효성 검사** — 검사 리포트

## 테스트 케이스

### TC-01: 칩 — 문서 서식 정리
- **입력**:
  - 서식이 들쭉날쭉한 본문에서 **"문서 서식 정리" 칩 클릭**
- **조작 순서**:
  1. 추천기능에서 "문서 서식 정리" 칩 클릭
  2. (옵션 제시 시 선택) → 적용, 결과 대기
- **기대 결과**: 본문 서식(줄간격·정렬·불필요 공백 등) 일괄 정돈
- **검증 포인트**: 칩 클릭만으로 동작 트리거됨 · 서식 일관성 향상 · 본문 텍스트 손실 없음 · 과도한 재작성 없음

### TC-02: 칩 — 내용 요약
- **입력**:
  - 본문이 채워진 상태에서 **"내용 요약" 칩 클릭**
- **조작 순서**:
  1. "내용 요약" 칩 클릭
  2. 응답 대기
- **기대 결과**: 본문 내용의 요약 결과 제시 (또는 요약본 삽입)
- **검증 포인트**: 칩 클릭만으로 트리거 · 요약이 본문 핵심 반영 · 빈 본문일 땐 안내 메시지 · 결과 형태(채팅 제시 vs 본문 삽입) note 기록

### TC-03: 칩 — 톤 변환
- **입력**:
  - 본문이 채워진 상태에서 **"톤 변환" 칩 클릭**
- **조작 순서**:
  1. "톤 변환" 칩 클릭
  2. 톤 선택지(예: 정중/캐주얼 등)가 뜨면 1개 선택 → 적용
- **기대 결과**: 선택한 톤으로 본문 어조 일괄 전환
- **검증 포인트**: 칩 클릭 시 톤 선택 UX 동작 여부 note · 선택 톤 일관 적용 · 내용 누락 없음 · (SCN-02·03 프롬프트형 톤 변환과 결과 비교 가능)

### TC-04: 칩 — 글머리 기호 정리
- **입력**:
  - 나열 항목이 있는 본문에서 **"글머리 기호 정리" 칩 클릭**
- **조작 순서**:
  1. "글머리 기호 정리" 칩 클릭
  2. 결과 대기
- **기대 결과**: 본문 나열 부분이 글머리 기호 목록으로 정리
- **검증 포인트**: 나열 항목이 불릿으로 표시 · 일반 문단은 목록화되지 않음 · 항목 수 보존

### TC-05: 칩 — EMS 메일 템플릿
- **입력**:
  - **"EMS 메일 템플릿" 칩 클릭**
- **조작 순서**:
  1. "EMS 메일 템플릿" 칩 클릭
  2. (템플릿 선택지 제시 시) 템플릿 1개 선택 → 적용
- **기대 결과**: EMS 형식 메일 템플릿이 본문에 적용
- **검증 포인트**: 템플릿 구조(머리말/본문/꼬리말 등) 삽입 · 깨짐 없음 · 기존 본문 처리 방식(덮어쓰기 vs 삽입) note 기록

### TC-06: 칩 — 에디터 내용 유효성 검사
- **입력**:
  - 본문이 채워진 상태에서 **"에디터 내용 유효성 검사" 칩 클릭**
- **조작 순서**:
  1. "에디터 내용 유효성 검사" 칩 클릭
  2. 결과 대기
- **기대 결과**: 본문 유효성 검사 리포트 제시 (문제 항목·개선 제안 등)
- **검증 포인트**: 검사 결과가 패널에 표시됨 · 본문을 임의 변경하지 않음(리포트형) · 항목별 안내 존재
