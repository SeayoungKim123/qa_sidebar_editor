# 시나리오: PPT 객체 삽입 — 표·차트·도형을 AI로 넣고 편집

## 메타 정보
- **ID**: SCN-04
- **우선순위**: P0
- **목적**: PPT 덱에서 ONLYOFFICE 우측 AI 사이드패널이 **표·차트·도형 등 객체를 슬라이드에 생성하고, 표 구조(셀 병합·행 추가)·차트 종류를 편집**하는 명령을 정확히 수행하는지 검증. `03-PPT-실사용흐름`이 텍스트·테마 흐름을 다룬다면, 이 시나리오는 **객체 삽입·구조 편집 축**을 전담한다.
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 파일 행 호버 → **두 번째 "미리보기 (MCP ver)" 플라스크 아이콘** 클릭 → Hiworks AI 탭 진입
  - 우측 AI 어시스턴트 사이드패널 노출, 모델 `GPT 5.4` 선택
  - **빈 PPTX 1개** 열림 (슬라이드 1장, 본문 비어 있음), 편집 모드 활성화
- **검증 규칙**: 슬라이드에 직접 타이핑·서식 조작 **금지**. 오직 AI 채팅창에 프롬프트만 전송하고, AI 가 객체를 삽입·편집하는지를 관찰·검증한다.

---

## 사용자 흐름

이 시나리오는 **자체 셋업으로 시작해 객체를 진화**시킨다 (다른 시나리오 산출물에 의존하지 않음). TC 는 순서대로 진행하며, 선행 TC 가 실패해 대상이 없으면 후속 TC 는 `BLOCKED`.

1. **셋업** — 빈 덱에 데이터 표 슬라이드를 AI로 생성
2. **표 구조 편집** — 셀 병합·행 추가
3. **차트** — 차트 슬라이드 삽입 후 종류 변경
4. **도형** — 강조 도형 삽입
5. 마지막에 저장 → 재오픈하여 객체 영속 확인

## 테스트 케이스

### 셋업 · 표 슬라이드 생성

#### TC-01: 매출표 슬라이드 생성
- **입력**:
  - 빈 1번 슬라이드 선택
  - 프롬프트: `"분기별 매출표(1Q~4Q, 매출액) 슬라이드를 1장 만들어줘. 매출액은 더미 숫자"`
- **조작 순서**:
  1. 좌측에서 1번 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**: 표(헤더 + 1Q~4Q + 더미 매출액)가 포함된 슬라이드
- **검증 포인트**: 표 셀 클릭 시 편집 가능 · 1Q~4Q 행 존재 · 한글 깨짐 없음

### 표 구조 편집

#### TC-02: 표 셀 병합 + 행 추가
- **입력**:
  - 매출표 슬라이드 선택
  - 프롬프트: `"매출표 헤더 위에 '2026 분기별 매출'이라는 행을 추가하고 전체 열을 하나로 병합해줘"`
- **조작 순서**:
  1. 표가 있는 슬라이드 → 표 클릭
  2. 프롬프트 전송
- **기대 결과**: 표 상단에 전체 너비로 병합된 제목 행 1개 추가
- **검증 포인트**: 병합 셀이 표 전체 너비 · 기존 1Q~4Q 데이터 무변동 · 다른 슬라이드 영향 없음 · 부분 적용 시 `FAIL`(note 기록)

### 차트

#### TC-03: 차트 슬라이드 삽입
- **입력**:
  - 프롬프트: `"매출표 데이터를 막대 차트로 보여주는 슬라이드를 1장 추가해줘. 제목 '분기별 매출 추이'"`
- **조작 순서**:
  1. 매출표 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**: 슬라이드 1장 추가, 막대 차트 + 제목 '분기별 매출 추이'
- **검증 포인트**: 좌측 패널 썸네일 1개 추가 · 차트 더블클릭 시 데이터 편집 가능 · 1Q~4Q 값이 표와 일치 · 기존 슬라이드 변형 없음

#### TC-04: 차트 종류 변경
- **입력**:
  - TC-03 차트 선택
  - 프롬프트: `"이 막대 차트를 꺾은선 차트로 바꿔줘"`
- **조작 순서**:
  1. 차트 클릭
  2. 프롬프트 전송
- **기대 결과**: 데이터를 유지한 채 차트 유형만 막대→꺾은선
- **검증 포인트**: 데이터 값/계열 변형 없음 · 차트 유형만 변경 · 제목 '분기별 매출 추이' 유지

### 도형

#### TC-05: 강조 도형 추가
- **입력**:
  - 차트 슬라이드 선택
  - 프롬프트: `"이 슬라이드 우측 상단에 'NEW' 라벨이 들어간 빨간색 둥근 사각형 강조 도형을 추가해줘"`
- **조작 순서**:
  1. 차트 슬라이드 선택
  2. 프롬프트 전송
- **기대 결과**: 우측 상단 둥근 사각형 1개, 텍스트 `NEW`, 빨강
- **검증 포인트**: 도형 화면 표시 · 텍스트 `NEW` 정확 · 차트/제목 변형 없음

#### TC-06: 저장/영속 확인
- **입력**:
  - 프롬프트 없음 (저장 동작만)
- **조작 순서**:
  1. 저장 → 파일 닫기 → 재오픈
  2. 슬라이드 순회하며 객체 확인
- **기대 결과**: 표 병합 구조·차트·도형이 재오픈 후에도 모두 유지
- **검증 포인트**: **재오픈 시 표 병합 행·차트·도형이 전부 영속**(하나라도 사라지거나 깨지면 `FAIL`, note 기록) · 슬라이드 순서 유지
