# 시나리오: DOCX 객체 삽입 — 표·차트·도형을 AI로 넣고 구조 편집

## 메타 정보
- **ID**: SCN-02
- **우선순위**: P0
- **목적**: DOCX 문서에서 ONLYOFFICE 우측 AI 사이드패널이 **표·차트·도형 등 객체(object)를 생성하고, 표 구조(행/열·셀 병합)를 편집**하는 명령을 정확히 수행하는지 검증. `01-DOCX-실사용흐름`이 텍스트·서식 흐름을 다룬다면, 이 시나리오는 **객체 삽입·구조 편집 축**을 전담한다.
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 파일 행 호버 → **두 번째 "미리보기 (MCP ver)" 플라스크 아이콘** 클릭 → Hiworks AI 탭 진입
  - 우측 AI 어시스턴트 사이드패널 노출, 모델 `GPT 5.4` 선택
  - **빈 DOCX 1개** 열림 (본문 없음), 편집 모드 활성화
- **검증 규칙**: 본문에 직접 타이핑·서식 조작 **금지**. 오직 AI 채팅창에 프롬프트만 전송하고, AI 가 객체를 삽입·편집하는지를 관찰·검증한다.

---

## 사용자 흐름

이 시나리오는 **자체 셋업으로 시작해 객체를 진화**시킨다 (다른 시나리오 산출물에 의존하지 않음). TC 는 순서대로 진행하며, 선행 TC 가 실패해 대상이 없으면 후속 TC 는 `BLOCKED`.

1. **셋업** — 빈 문서에 기준 표를 AI로 생성
2. **표 구조 편집** — 행 추가·셀 병합·열 추가
3. **차트** — 차트 삽입 후 종류 변경
4. **도형·이미지** — 강조 도형·로고 자리표시 삽입
5. 마지막에 저장 → 재오픈하여 객체 영속 확인

## 테스트 케이스

### 셋업 · 기준 표 생성

#### TC-01: 기준 표 생성
- **입력**:
  - 빈 문서, 본문 맨 위 커서
  - 프롬프트: `"분기별 추진일정표를 만들어줘. 4행 3열, 헤더는 분기/과제/담당, 1Q~3Q 더미 데이터 채워줘"`
- **조작 순서**:
  1. 본문 맨 위 클릭 (위치만 지정, 직접 입력 금지)
  2. 프롬프트 전송 → 응답 대기
- **기대 결과**: 4행 3열 표 삽입, 첫 행 헤더(분기/과제/담당), 아래 3행 더미(1Q~3Q)
- **검증 포인트**: 표 셀 클릭 시 편집 가능 · 헤더/데이터 행 구분 · 한글 깨짐 없음

### 표 구조 편집

#### TC-02: 행 추가 + 셀 병합
- **입력**:
  - 프롬프트: `"표 맨 아래에 4Q 행을 한 줄 추가하고, 헤더 위에 '2026 추진일정'이라는 제목 셀을 표 전체 너비(3열)로 병합해서 넣어줘"`
- **조작 순서**:
  1. 표 클릭 (선택)
  2. 프롬프트 전송
- **기대 결과**: 데이터 행 1개(4Q) 추가 + 표 최상단에 3열이 1셀로 병합된 제목 행 생성
- **검증 포인트**: 추가 행이 기존 서식과 일치 · 병합 셀이 표 전체 너비 차지 · 기존 1Q~3Q 데이터 무변동 · 부분 적용(행만 or 병합만)되면 `FAIL`(누락 note 기록)

#### TC-03: 열 추가
- **입력**:
  - 프롬프트: `"표 오른쪽 끝에 '진행률' 열을 하나 추가하고, 데이터 행에는 0%로 채워줘"`
- **조작 순서**:
  1. 표 클릭 (선택)
  2. 프롬프트 전송
- **기대 결과**: 맨 오른쪽에 '진행률' 열 추가(헤더 + 각 데이터 행 0%)
- **검증 포인트**: 병합된 제목 행 너비가 새 열까지 자동 확장 · 기존 3개 열 데이터 무변동 · 표 외부 본문 영향 없음

### 차트

#### TC-04: 차트 삽입
- **입력**:
  - 프롬프트: `"표 아래에 분기별 과제 수를 보여주는 막대 차트를 하나 삽입해줘. 제목은 '분기별 과제'"`
- **조작 순서**:
  1. 표 끝 아래에 커서
  2. 프롬프트 전송
- **기대 결과**: 본문에 막대 차트 1개 삽입, 제목 '분기별 과제'
- **검증 포인트**: 차트가 본문에 배치(인라인/플로팅) · 차트 더블클릭 시 데이터 편집 진입 가능 · 표·기존 내용 변형 없음

#### TC-05: 차트 종류 변경
- **입력**:
  - TC-04 차트 선택
  - 프롬프트: `"이 막대 차트를 꺾은선 차트로 바꿔줘"`
- **조작 순서**:
  1. 차트 클릭 (선택)
  2. 프롬프트 전송
- **기대 결과**: 데이터를 유지한 채 차트 유형만 막대→꺾은선
- **검증 포인트**: 데이터 값/계열 변형 없음 · 차트 유형만 변경 · 제목 '분기별 과제' 유지

### 도형·이미지

#### TC-06: 강조 도형 삽입
- **입력**:
  - 프롬프트: `"문서 맨 위에 '초안'이라는 텍스트가 들어간 빨간색 둥근 사각형 강조 도형을 추가해줘"`
- **조작 순서**: (문서 맨 위 커서) 프롬프트 전송
- **기대 결과**: 둥근 사각형 1개, 텍스트 `초안`, 빨강
- **검증 포인트**: 도형 화면 표시 · 텍스트 `초안` 정확 · 본문 표/차트 변형 없음

#### TC-07: 로고 자리표시 삽입 + 저장/영속
- **입력**:
  - 프롬프트: `"문서 맨 위 제목 영역에 회사 로고 자리표시용 도형(회색 사각형 + '로고' 텍스트)을 가운데 정렬로 넣어줘"`
- **조작 순서**:
  1. 프롬프트 전송
  2. 응답 반영 후 저장 → 문서 닫기 → 재오픈
- **기대 결과**: 회색 사각형 + '로고' 텍스트(가운데 정렬), 재오픈 후에도 표·차트·도형 모두 유지
- **검증 포인트**: 도형 가운데 정렬 · **재오픈 시 표 병합 구조·차트·도형이 전부 영속**(하나라도 사라지면 `FAIL`, note 기록)

> 참고: 실제 이미지 파일 업로드가 가능한 환경이면 TC-07 프롬프트를 `"... 이미지를 삽입해줘"`로 바꾸고 파일 선택 단계를 조작 순서에 추가한다.
