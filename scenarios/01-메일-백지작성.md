# 시나리오: 메일 AI 사이드패널 — 백지에서 컨텐츠 채우기

## 메타 정보
- **ID**: SCN-01
- **우선순위**: P0
- **목적**: 실제 사용자가 **빈 메일 본문에서 시작해 AI 사이드패널 명령만으로 완성된 메일을 단계적으로 쌓아 올리는** 흐름을 따라가며, Hiworks 메일 쓰기 우측 AI 어시스턴트가 자연어 요청을 받아 에디터 본문을 정확히 채우는지 검증
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 메일 → **메일 쓰기** 진입, 본문 에디터 빈 상태
  - 상단 **보라색 AI 아이콘** 클릭 → 우측 AI 어시스턴트 사이드패널 노출 ("메일 작성을 도와드릴게요" + 추천기능 칩 표시)
  - "작성 중인 메일 참조 중" 배지 활성 확인
- **검증 규칙**: 본문에 직접 타이핑·서식 조작 **금지**. 오직 AI 채팅창에 프롬프트만 전송하고, AI 가 본문을 편집하는지를 관찰·검증한다. **AI 는 본문만 편집** — 제목(Subject)·받는사람 칸은 검증 대상 아님.

---

## 사용자 흐름

이 시나리오는 **하나의 메일이 단계적으로 진화**한다. 앞 단계 산출물을 뒤 단계가 보강하므로 TC 는 순서대로 진행하며, 선행 TC 가 실패해 대상이 없으면 후속 TC 는 `BLOCKED`.

1. **초안 생성** — 빈 본문에 AI 로 메일 초안 작성
2. **단락 보강** — 초안에 연락처·문의 안내 등 추가 단락 삽입
3. **격식 골격** — 인사말·맺음말로 비즈니스 메일 골격 완성
4. **나열 정보** — 본문 중간에 제품 특징 등 나열 정보 추가
5. 각 단계 후 화면 반영 확인

## 테스트 케이스

### TC-01: 메일 초안 작성 (백지)
- **입력**:
  - 빈 본문, 커서 본문 맨 위
  - 프롬프트: `"거래처에 신제품 출시를 안내하는 비즈니스 메일 초안을 작성해줘. 출시일과 핵심 가치를 포함해서"`
- **조작 순서**:
  1. 본문 영역 클릭 (커서 위치만 지정, 직접 입력 금지)
  2. 채팅창에 프롬프트 전송 → 응답 대기 (필요 시 "본문에 삽입")
- **기대 결과**: 본문에 한국어 비즈니스 메일 초안 삽입 (인사 → 본론 → 안내 흐름)
- **검증 포인트**: 본문 글자 수 150자 이상 · 신제품/출시 맥락 반영 · 깨짐 없음 · 받는사람/제목 칸 무변동

### TC-02: 단락 추가
- **입력**:
  - TC-01 초안이 채워진 상태
  - 프롬프트: `"메일 끝에 담당자 연락처와 문의 안내 단락을 추가해줘"`
- **조작 순서**:
  1. 본문 끝에 커서 (또는 선택 없이 전송)
  2. 프롬프트 전송
- **기대 결과**: 기존 초안 끝에 연락처·문의 안내 단락 1개 추가
- **검증 포인트**: TC-01 초안 본문 변형 없음 · 새 단락이 끝에 위치 · 연락처/문의 문구 포함

### TC-03: 인사말·맺음말 골격
- **입력**:
  - 프롬프트: `"메일 맨 앞에 정중한 비즈니스 인사말, 맨 끝에 맺음말을 넣어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 앞에 인사말, 끝에 맺음말 추가되어 메일 격식 완성
- **검증 포인트**: 인사말이 최상단·맺음말이 최하단 · 중간 본문(초안+연락처) 순서 유지 · 중복 인사말 없음

### TC-04: 나열 정보 삽입
- **입력**:
  - 프롬프트: `"본문 중간에 신제품 주요 특징 3가지를 넣어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 본문 중간에 특징 3개 항목 삽입
- **검증 포인트**: 3개 항목 모두 존재 · 인사말/맺음말 바깥에 위치하지 않음 · 기존 단락 손상 없음
