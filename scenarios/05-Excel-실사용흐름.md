# 시나리오: Excel 실사용 흐름 — 백지에서 매출 시트 만들고 분석

## 메타 정보
- **ID**: SCN-05
- **우선순위**: P0
- **목적**: 실제 사용자가 매출 관리 시트를 **빈 시트에서 시작해 단계적으로 완성·분석**하는 흐름을 따라가며, ONLYOFFICE 우측 AI 사이드패널이 Excel 의 특성(셀/데이터 타입·수식·서식·차트)에 맞게 명령을 정확히 수행하는지 검증
- **사전 조건**:
  - 테스트 계정 로그인 (`environments/{env}.md`)
  - 파일 행 호버 → **두 번째 "미리보기 (MCP ver)" 플라스크 아이콘** 클릭 → Hiworks AI 탭 진입
  - 우측 AI 어시스턴트 사이드패널 노출, 모델 `GPT 5.4` 선택
  - **빈 XLSX 1개** 열림 (Sheet1 비어 있음), 편집 모드 활성화
- **검증 규칙**: 셀에 직접 타이핑·서식 조작 **금지**. 오직 AI 채팅창에 프롬프트만 전송하고, AI 가 셀/수식/서식을 편집하는지를 관찰·검증한다.

---

## 사용자 흐름

이 시나리오는 **하나의 시트가 단계적으로 진화**한다. 앞 단계 산출물을 뒤 단계가 수정하므로 TC 는 순서대로 진행하며, 선행 TC 가 실패해 대상이 없으면 후속 TC 는 `BLOCKED`.

1. **1단계 (백지)** — 빈 시트에 표·데이터·기초 수식을 AI로 생성
2. **2단계 (개별)** — 특정 행/열/셀의 서식·수식을 콕 집어 수정
3. **3단계 (일괄)** — 표 전체 서식·차트 등 시각 요소를 한 번에 구성
4. 각 단계 후 셀 값/수식 입력줄/화면 반영 확인, 마지막에 저장 → 재오픈하여 영속 확인

## 테스트 케이스

### 1단계 · 백지에서 작성

#### TC-01: 매출 표 만들기
- **입력**:
  - Sheet1 빈 상태, A1 선택
  - 프롬프트: `"A1부터 직원 3명의 1~3월 매출표를 만들어줘. 헤더는 이름/1월/2월/3월, 매출 더미 숫자 채워줘"`
- **조작 순서**:
  1. A1 클릭 (위치만 지정, 직접 입력 금지)
  2. 프롬프트 전송
- **기대 결과**: A1:D1 헤더(이름/1월/2월/3월), A2:D4 직원 3명 데이터(이름 텍스트 + 월별 숫자)
- **검증 포인트**: 월별 매출 셀이 숫자 타입(우측 정렬) · 이름 텍스트 · 표 외 영역 무변동

#### TC-02: 합계 행 추가 (수식)
- **입력**:
  - 프롬프트: `"표 아래 합계 행을 추가하고, 각 월 컬럼(B~D) 합계를 SUM 수식으로 넣어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: 5행에 '합계' 라벨 + B5:D5 에 `=SUM(B2:B4)` 형태 수식
- **검증 포인트**: B5 클릭 시 수식 입력줄에 SUM 수식(텍스트 값 아님) · 합계 수동 검산 일치

#### TC-03: 총합 컬럼 추가 (수식)
- **입력**:
  - 프롬프트: `"E열에 '총합' 컬럼을 추가하고, 각 직원의 1~3월 합계를 SUM 수식으로 넣어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: E1 헤더 '총합', E2:E4 에 `=SUM(B2:D2)` 형태 (상대 참조)
- **검증 포인트**: E2 클릭 시 수식 표시 · 직원별 행 합과 일치 · 합계 행과 총합 컬럼 교차셀(E5) 처리 확인

### 2단계 · 개별 요소 수정 (1단계 산출물 대상, 선행 의존)

#### TC-04: 헤더 행 서식
- **입력**:
  - 헤더 행(A1:E1) 선택
  - 프롬프트: `"선택한 헤더 행을 굵게 + 글자 크기 14pt + 배경색 연회색(#E5E5E5)으로 해줘"`
- **조작 순서**:
  1. A1:E1 드래그 선택 (선택만)
  2. 프롬프트 전송
- **기대 결과**: 헤더 행 셀이 굵게, 14pt, 배경 연회색
- **검증 포인트**: 폰트 `14` 표기 · 굵게 표시 · 데이터/합계 행 무변동

#### TC-05: 통화 형식 적용
- **입력**:
  - 매출 숫자 영역(B2:E5) 선택
  - 프롬프트: `"선택한 매출 셀들을 한국 원화(₩) 통화 형식으로 바꿔줘"`
- **조작 순서**:
  1. B2:E5 드래그 선택
  2. 프롬프트 전송
- **기대 결과**: 각 셀 값 앞 `₩` 표시, 실제 데이터 값은 유지(서식만 변경)
- **검증 포인트**: 셀 클릭 시 수식 입력줄에는 숫자만 · 서식 메뉴 "통화" 선택 상태 · 헤더 행 영향 없음

#### TC-06: 조건부 IF 수식
- **입력**:
  - 프롬프트: `"F열에 '평가' 컬럼을 추가하고, 각 직원 총합(E열)이 1000 이상이면 '우수', 미만이면 '보통'을 표시하는 IF 수식을 넣어줘"`
- **조작 순서**: (선택 없이) 프롬프트 전송
- **기대 결과**: F2 에 `=IF(E2>=1000,"우수","보통")` 형태, F2:F4 동일 패턴(상대 참조)
- **검증 포인트**: F2 클릭 시 IF 수식 표시(텍스트 값 아님) · 기준값에 따라 우수/보통 정확 · 직원 행 모두 채워짐

### 3단계 · 여러 요소 일괄 수정 (전체 재서식·시각화)

#### TC-07: 표 전체 정렬 + 테두리
- **입력**:
  - 데이터 표 영역(A1:F5) 선택
  - 프롬프트: `"선택 영역을 가운데 정렬하고, 모든 셀에 얇은 검은색 테두리를 적용해줘"`
- **조작 순서**:
  1. A1:F5 드래그 선택
  2. 프롬프트 전송
- **기대 결과**: 모든 셀 가운데 정렬 + 테두리 격자
- **검증 포인트**: 정렬 가운데 표기 · 테두리 시각 확인 · 표 외부 무변동

#### TC-08: 막대 차트 생성
- **입력**:
  - 프롬프트: `"직원별 1~3월 매출 데이터로 막대 차트를 만들어줘. 차트 제목은 '1분기 매출', 가로축은 직원, 세로축은 매출액"`
- **조작 순서**:
  1. 데이터 범위(A1:D4) 드래그 선택
  2. 프롬프트 전송
- **기대 결과**: 막대 차트 1개 삽입, 제목 '1분기 매출', 직원별 월 매출 막대
- **검증 포인트**: 차트 화면 표시 · 데이터 변경 시 막대 높이 자동 갱신 · 제목 텍스트 정확

#### TC-09: 차트 디자인 수정
- **입력**:
  - TC-08 차트 선택
  - 프롬프트: `"이 차트 색상을 파랑 계열로 바꾸고, 가로축 글자 크기 12pt, 격자선을 제거해줘"`
- **조작 순서**:
  1. 차트 클릭
  2. 프롬프트 전송
- **기대 결과**: 막대 파랑 계열 + 가로축 라벨 12pt + 격자선 비표시
- **검증 포인트**: 세 항목 모두 반영돼야 `PASS`, 하나라도 빠지면 `FAIL`(누락 note 기록) · 차트 데이터 변형 없음
